# HealthQueue---Smart-Patient-Management-System
HealthQueue is a smart hospital management system for managing patient records, appointments, queues, and emergency priorities. It supports adding, searching, updating, deleting, and sorting patient data, along with online doctor appointment booking and time-slot selection.
